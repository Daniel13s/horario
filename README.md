#Horário

Este é um projeto simples realizado para treinar habilidades como npm e JavaScript, com o intuito de pegar o horário e a data do seu aparelho e exibir na tela em forma de site.

##Como usar?
Para usar esse script, siga os seguintes passos:

1- **Instale o Node** em sua máquina, para o uso do projeto.
  Se o Node não estiver instalado, acesse o site: [https://nodejs.org/pt]
2- Clone o repositório usando o comando:
  <code>git clone https://github.com/Daniel13s/horario</code>
3- **Instale as dependencias** na pasta que clonou:
  -npm: <code>npm init es6 -y</code>
  -parcel: <code>npm i parcel</code>
  -dayjs: <code>npm i dayjs</code>

  -No arquivo **package.json** troque o <code>"main" : ""</code> por <code>"source": "src/index.html"</code>
  -No arquivo **package.json** coloque o valor de  <code>"dev" : ""</code> para <code>"dev": "parcel index.html"</code>
4- **Execute** o arquivo digitando no terminal <code>npm run dev</code>

**E pronto**, basta clicar no link e abrir o site🎉!
